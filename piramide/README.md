# Pirâmide 3D em OpenGL

Projeto desenvolvido em **C com OpenGL e GLUT**, mostrando uma pirâmide 3D com diferentes transformações geométricas.

## Funcionalidades

* **Translação** — movimenta a pirâmide
* **Rotação** — gira a pirâmide
* **Escala** — aumenta ou diminui o tamanho
* **Espelhamento** — altera a orientação do objeto
* **Reset** — retorna ao estado inicial

## Controles

| Tecla | Função       |
| ----- | ------------ |
| `T`   | Translação   |
| `R`   | Rotação      |
| `S`   | Escala       |
| `M`   | Espelhamento |
| `I`   | Reset        |

As **setas direcionais** controlam a transformação selecionada.

## Tecnologias

* C
* OpenGL
* GLUT

## Objetivo

Praticar **transformações geométricas e renderização 3D** utilizando OpenGL.
